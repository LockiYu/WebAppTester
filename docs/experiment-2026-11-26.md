# 追加实验：B0–B3 的重复运行与证据校验

## 为什么补做

2026-10-19 的三应用试跑每个场景、每种配置只运行一次。两批独立试跑中的 UNKNOWN 落在不同单元格，单次 PASS 数不适合解释方案的稳定性。课程的正式 36 场景及标准答案尚未到位；这里的追加实验使用本地测试应用，检验重复运行行为和证据契约的作用。

## B0 包含的能力

B0 仍使用 Planner 拆检查点、Executor 操作浏览器、Verifier 给出结构化检查点状态，并保留截图、Trace、报告和步数上限。B0 关闭证据来源校验、缺口反馈和预算仲裁；B1、B2、B3 依次加入这三项机制。

## 实验一：真实浏览器重复试跑

- 环境：隔离的 4gaBoards 3.2.16；本地 Ollama `qwen3.5:9b`；每次最多 5 个浏览器操作。
- 场景：① 已存在项目同时出现在仪表盘和侧栏；② 仪表盘的 Add Project 按钮可见，不点击按钮。
- 独立标准答案：测试前用 Playwright 分别确认项目在两个区域各出现一次，按钮可见。两个场景的预期结论均为 PASS。
- 方法：每种配置、每个场景运行 3 次；三轮改变 B0–B3 的执行顺序。每次运行保留独立报告、事件、截图和 Trace。公开的逐次汇总见 [CSV](data/repeat-4ga-2026-11-26.csv)；原始页面证据仅保存在本机被 Git 忽略的 `runs/repeat-4ga/20261126T065556Z/`。

| 配置 | 项目双区域 PASS / 3 | 按钮可见 PASS / 3 | 合计 PASS / 6 | UNKNOWN / 6 | 平均操作步数 | 平均耗时 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| B0 | 3 | 3 | 6 | 0 | 2.17 | 36.3 秒 |
| B1 | 0 | 3 | 3 | 3 | 3.17 | 80.0 秒 |
| B2 | 1 | 2 | 3 | 3 | 3.00 | 65.1 秒 |
| B3 | 1 | 2 | 3 | 3 | 3.33 | 76.8 秒 |

九次 UNKNOWN 中，B1、B2、B3 各有三次；其中六次发生在跨区域场景的 5 步预算耗尽。B1 另有一次执行器主动停止；B2 的按钮场景有一次模型输出错误；B3 的按钮场景有一次动作恢复耗尽。具体逐次原因见 CSV。这个压力设置下，B0 的完成率更高；加入证据和补查机制会消耗额外模型调用与操作步数。由于只有两个正例场景，不能从这张表估计真实缺陷检出率或误报率。

## 实验二：受控无效证据

用同一个“Preferences 标题可见”检查点和同一份观察记录，分别提交四种结构化证据给裁决函数。这个实验不调用模型，也不测浏览器任务成功率，只检查结论门控。

| 输入证据 | B0 结论 | B1 结论 |
| --- | --- | --- |
| 正确观察、正确引文、正确标题区域 | PASS | PASS |
| 引用不存在的观察 ID | PASS | UNKNOWN |
| 引文不是页面原文 | PASS | UNKNOWN |
| 标题检查点引用侧栏区域 | PASS | UNKNOWN |

B0 按 Verifier 提交的结构化 SAT 状态裁决；B1 要求证据能回指真实观察和对应区域。受控实验说明证据契约可以阻止三类无效引用被报成 PASS，但不抵消实验一观察到的执行成本。

## 对中期结果的解读

2026-10-19 那批三应用试跑中，B1 的 UNKNOWN 出现在 Admidio 的 Preferences 标题场景。浏览器观察已到达目标页，并记录到 `heading[1]="Preferences"`；随后 Verifier 的结构化输出两次未通过解析或校验，事件记录为 `verifier_output_rejected` / `ModelOutputError`。下一次浏览器点击又失败，最终报告 UNKNOWN。该事件没有保存完整原始输出和具体被拒字段，因此只能确认核验输出未被系统接受，不能断言标题判断本身错误，也不能归因于某一条特定证据规则。B0 在相应场景得到 PASS，说明它较宽松的裁决路径完成了该次任务；两者各运行一次不足以比较稳定成功率。

先导试跑主要证明三应用流程和 B0–B3 运行工具可以工作。追加实验表明，同一模型重复运行时输出与动作路径会变化；B0 的一次 3/3 与 B1 的一次 2/3 不能直接解释为稳定的性能差异。正式效果评测需要课程场景与标准答案、可恢复的应用初始状态，以及各配置的多次同条件运行；应同时报告正确结论、错误 PASS、UNKNOWN、操作步数、Token 和耗时。

一次尝试复跑旧 Admidio 英文标题场景时，当前本地界面已切换为中文，原英文场景不再匹配，因此该尝试没有纳入上述统计。
